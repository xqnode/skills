# 画面要求

右上角不放文字，左上角使用「程序员青戈 / 本节技术要点」。本示例为「程序员青戈 / HTTP请求、后端查询与页面更新」；新主题须替换为对应技术内容，不沿用「编程图解」等泛称。

1920×1080，默认30fps，手绘文楷字体、轻微弯曲墨线、极淡纸纹。图形为主，橙色请求、蓝色返回；无点阵、无斜纹阴影，一次最多一条红色批注，已完成路径淡化。字幕50px、尾部无标点。

当前浏览器、后端、数据库及六步状态仅是已验收的网页请求示例。新主题应重新设计对象与动作，按scene.json的真实词组锚点同步，提示不抢在动作之前，完成标记在动作结束后。预览和导出共用renderAt(t)，不使用真实时间、随机数或独立CSS动画决定关键帧。
