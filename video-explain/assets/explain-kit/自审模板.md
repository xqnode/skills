# 自审记录

复制到样片目录，命名为 `自审.md`。`scene.mjs video` 导出前会检查：本文件比 `index.html` 和联系表都新，且抽帧资源指纹与当前所有已加载依赖一致；十个类别每行都写了「通过」；没有残留「不通过」；至少列出 4 张亲眼看过的原尺寸关键帧；「遮挡」一行写出至少 4 张逐张查过的帧名。改了页面、模块、时间线或其他依赖就要重新生成关键帧、重新填写本文件。

## 失败清单（对照 references/animation.md 第 7 节）

每行写「通过」，并给出依据（时间点、看到的画面）；发现问题先改、重新生成关键帧，再改成通过。

| 类别 | 结论 | 依据 |
| --- | --- | --- |
| 因果 | 待填 | 关掉声音能否看懂每一步 |
| 时序 | 待填 | 逐个关键词核对：结果、摘要内容、结论没有早于关键词 |
| 事实 | 待填 | 没有把可能画成必然；角色没表现它不知道的事；缺失用空位表达 |
| 构图 | 待填 | 无重复构图、无一侧空一侧挤；主体占画面一半以上；开场 1 秒内出现主体；角色全程在场；与上一幕舞台的延续或交代 |
| 遮挡 | 待填 | 逐张看原尺寸单帧，写出帧名（至少 4 张，例如 still-3.000.png、still-12.500.png…）：无文字重叠、细边框擦字，洗色条、高亮条不压字；右上角与字幕区（y>950）无内容；用户指出的时刻及前后帧已复查 |
| 指向 | 待填 | 每个箭头、连线、批注指向：写明从哪个对象指到哪个对象，并列出它出现、完全显示、和相邻物件同时在场、消失这几帧；终点落在要指的对象上，不落在空白处或容器边上；箭头已用 target 声明对象，自动检查没有「指向」「细线压字」错误 |
| 接触 | 待填 | 压、夹、推、接住、放入等动作：两者真的贴合，不留空隙；写出每个动作开始、中间、结束三帧的帧名 |
| 可读性 | 待填 | 正文 ≥22px，说明文字用 sub，橙色说明 ≥26px 且用 orangeD；字与进度条、无关边框及相邻标签有清楚留白，写明所查说明区及实际净距或视觉依据 |
| 风格 | 待填 | 无全局抖动、点阵、斜纹；橙=动作/问题，蓝=返回/保留 |
| 字幕 | 待填 | 尾部无句末标点；引用原话的「」由真实时间和原稿同源生成，不直接改字幕或CUES，句尾的 」 保留 |
