# 阶段、确认与重建范围

## 工作流程

**固定顺序：文稿确认 → 读法与配音设置 → 试听确认 → 全文音频与真实时间 → 字幕与动作分镜 → 样片确认 → 全片制作、自审与导出。**

每份经用户确认的文字稿，先建立独立的 `视频/主题名称/` 目录，再在其中推进制作。文稿、读法/配音/画面要求和配置放顶层，音频与生成记录放 `assets/`，检查记录与成片放 `output/`；不要散放到根目录或其他视频目录。共用脚本和模板留在 Skill。

### 阶段、产物与推进条件

文稿阶段的具体打磨方法见 [script-review.md](script-review.md)。文字技术审核通过、作者确认文稿、试听通过和全文听审通过是不同的状态，分别记录；不把其中一项自动扩大成后一项已经通过。

| 阶段 | 本阶段产物与要求 | 进入下一阶段的条件 |
| --- | --- | --- |
| 1. 文稿确认 | 明确讲解内容、输入输出与解释顺序，形成 `稿子.txt`；审稿时区分事实、推论和演示示例，核对因果前提、实验适用范围及【可能／一定】等限定，不把其他任务的测试结果直接当作当前场景的原因证明；纯正文不夹入表演说明 | 用户确认正文，或已明确授权使用指定稿件；未确认稿件不得自动视为定稿 |
| 2. 读法与配音设置 | 按 [voice-direction.md](voice-direction.md) 写 `读法规则.md`、`配音设置.md`：讲解语气、分段意图、术语读音、重点、停连及实际合成控制；同步对应配置 | 已有音色、正常语速等约定直接沿用；常规落实无需逐文件确认。更换已定音色、工具或表达方向时先说明影响并确认；调用合成接口须在已有授权范围内 |
| 3. 试听确认 | 生成代表性片段，实际检查讲师表达、术语、重音与停连；`--sample` 不替换全文音轨；交付可播放试听并主动询问是否合格，见下方「阶段结束时主动询问」 | 用户确认声音和表达后生成全文；已有试听确认直接沿用，用户明确要求生成全文时不重复审批；不能只凭音色参数或读法备注宣称听审通过 |
| 4. 全文音频与真实时间 | 保存实际请求、原始音频、真实字/词时间、拼接位置、额外静音及后期参数，完成音频技术检查 | 明确本轮采用的音轨版本，正文与时间数据对应、无待处理的音频错误或已知修改，才视为【音频固定】。用户指定的现有音轨直接沿用；技术通过不等于用户已完整听审 |
| 5. 字幕与动作分镜 | 先依据固定音轨的真实字/词时间生成字幕与SRT，再按 [animation.md](animation.md) 写每句主动作、关键词锚点、固定角色及完成状态，记录到动作分镜和 `画面要求.md`；完成主代理自查后主动询问是否需要独立审核 | 先审分镜，再写动画；落实下方「阶段结束时主动询问」的审核选择，字幕、SRT与页面CUES同源，动作和结果顺序核对通过。视觉隐喻可在写稿时构思，但精确到秒的动作分镜必须等音频固定后再定 |
| 6. 样片确认 | 选1～2个名场面，先做15～30秒样片；生成关键帧联系表，实际查看原尺寸帧，按失败清单自审、修正后导出样片 | 用户确认样片的视觉方向后再铺开全片；已确认方向直接沿用。用户只要求做样片时，完成样片交付即止，不自动扩成全片 |
| 7. 全片制作、自审与导出 | 按已确认方向完成动画，依 [storyboard-review.md](storyboard-review.md) 检查播放、跳转、资源、字幕、动作先后、遮挡与移动端预览；完成关键帧自审及工具要求的自动检查，再逐帧导出 | 导出后检查完整解码、音视频规格、实际播放与静止段；静止段超标先补有含义的动作并导出新版本。交付可播放结果，请用户完整听看；技术检查、自审、独立审核与用户验收分别记录 |

### 阶段结束时主动询问

这两个节点是必做的交付动作，不能只报「已完成」或宣布下一步，等用户自己提出确认或审核。

- **试听交付后问是否合格**：先生成可播放文件、完成本轮实际检查并说明尚存问题，再明确询问「这版试听是否合格，可以沿用这套声音和表达生成全文吗？」。记录具体文件/版本和用户结论；需调整则只改相关部分，重新交付后再确认。已有对应版本的确认或用户已明确要求生成全文时直接沿用授权，不重复问；工具好评、技术检查通过、未回复均不能当成用户确认。
- **完整分镜完成后问是否审核**：先写完可审阅的分镜、完成主代理自查、提供文件，再主动询问「是否需要独立子代理审核这版分镜，还是只做主代理自查后继续？」。不把分镜附上一句「可审核」当作已经询问。用户选择前，不自行启动子代理或推进动画；已有本轮独立审核授权直接执行，已有本轮免独立审核决定直接沿用，不重复问。独立审核的模型、档位、上下文隔离与只读范围遵守用户当前约定；收到报告后先汇总，修改是否执行按既有授权判断。
- 把试听确认、主代理自查、独立审核和用户对分镜的意见分别记录；没有回复不等于通过，也不等于不需要审核。用户改变已确认版本的声音或分镜方向时，只重开受影响的确认节点，不重走全部流程。

### 执行约束

- 已确认的决定、素材和授权直接沿用，不为每一步机械增加确认。仅制作某一阶段时，从已有材料和进度接续，不重做已验收环节；实际缺少的前置材料不得伪造或默认已确认。
- 读法须体现技术讲师面向学习者解释概念、因果和转折；语速与停顿分别控制，不给每句话加表演标签，不照搬示例秒数。
- 不按字数均分发音时间。动作锚定真实关键词，提示随动作出现，结果与完成标记不得早于动作结束。字幕按完整意思断句，不把整段长配音当一条字幕；去掉尾部句号、逗号、问号等标点及装饰性弯引号，保留引用原话的「」，包括句尾的」（如 `却没有保留「不要引入新依赖」`）。
- 预览和导出共用 `renderAt(t)`，支持任意跳转和重复定位；不使用随机数、独立CSS动画或播放经过时间决定画面。配音是播放时钟，失败显示错误，不以无声播放代替成功。
- 独立审核按用户授权执行，已授权不重复询问；未经授权不自行启动。审核先只读，修改按本轮授权执行。不能把时长相近或检查报告通过等同音画感知同步或用户验收，参见 [accepted-case.md](accepted-case.md)。

### 前置内容变更后的重建范围

- **文稿或实际读法改变**：回到受影响的正文、读法规则与合成配置；需要改变实际发音的片段重新生成，重建真实时间、拼接位置、字幕/SRT/CUES和受影响动作锚点。片段时长变化时同步更新后续绝对时间，不能继续沿用旧时间线。
- **音频剪辑、停顿或语速改变**：重新固定音轨并按真实音轨重建时间数据、字幕和动作时序；不能直接修改生成后的字幕或CUES来掩盖不同步。仅音量变化且采样长度不变时，核对一致后可沿用时间，但要更新音轨并重新导出。
- **仅字幕断句或显示文字修正**：修改字幕源规则/映射并统一重建字幕、SRT和CUES；不改变实际发音时不重合成音频，不重估词时间。
- **仅分镜或画面改变**：沿用已固定音频与真实时间；重新生成受影响关键帧、完成自审及自动检查后导出新版本。方向发生实质变化时先确认新样片，再继续全片。
- 保留已有确认素材和旧版成片，不覆盖旧版本，不因局部修改自动重做整条视频。
