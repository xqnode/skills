# 双比例检查

依赖Pillow，只有环境缺少时才安装。脚本不改输入文件、不覆盖既有检查结果。

```bash
python scripts/check_cover.py cover.png --out-dir qa
```

输出全图、中央4:3裁切、320×240缩略图、安全区辅助线及 report.json。
返回0表示几何检查通过；2表示比例、留白或矩形越界；1表示参数/输入错误。
辅助线图不能上传。

可选 `--boxes boxes.json` 格式：
```json
{"boxes":[{"label":"主标题","bbox":[330,280,1580,650]}]}
```
矩形坐标是实际成图像素 [left,top,right,bottom]，不是设计计划值。

留白检测假定两侧近白；任何RGB通道低于213的像素计为显著内容，占单侧缓冲0.3%以上报告失败。
可发现原案例的黑色标题与青蓝图标越界；不是OCR，不检测文字含义，也可能遗漏浅色文字。
有意允许边缘装饰时可加 --allow-side-decoration，但必须同时提供实际关键内容矩形并人工确认；默认不启用。
查看两种比例和缩略图，确认标题完整、错字和着色范围，不能只依赖返回码。
